# Unsplash Photo Gallery

A responsive photo gallery built with HTML, CSS, and JavaScript using the Unsplash API.

## Features

- Fetch random photos from the Unsplash API
- Responsive photo gallery layout
- Infinite scrolling to load more photos
- Loading animation while images are loading
- Click on a photo to open its original page on Unsplash

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Unsplash API

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Mahsaazadi-hub/Unsplash-photo-gallery.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

**Note:** This project uses the Unsplash API. You may need to configure your own API access key in the JavaScript file.
